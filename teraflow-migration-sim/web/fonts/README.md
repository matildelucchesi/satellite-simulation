# Local fonts

Inter and Space Grotesk are redistributed with their accompanying SIL Open Font License files. The application loads only these local assets and has no runtime CDN dependency.

Sources: Google Fonts repository, `ofl/inter/Inter[opsz,wght].ttf` and `ofl/spacegrotesk/SpaceGrotesk[wght].ttf`. The campaign artifact manifest records the exact local file checksums, including licenses.
